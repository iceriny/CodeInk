CodeInkPowerPoint 代码高亮 · Iceriny1.0.2

让代码清晰呈现，保持可编辑

在“代码高亮”选项卡中设置语言、主题和字体，将代码变为可编辑的文字或表格。

开始使用

  1. 选中包含代码的文本框或表格。
  2. 选择代码语言与配色主题。
  3. 点击“高亮排版”更新所选对象，或点击“生成代码块”创建逐行表格或组合文本框。

剪贴板中的纯文本可直接用“粘贴为代码”插入。选中文字时会处理整个文本框；在单元格中选中文字时会处理整张表格。

保留代码原有空格与缩进取消“自动整理代码”
更新已有代码块勾选“替换原对象”，再点击“生成代码块”

自动整理代码

默认整理明确的运算符空格、参数间距和缩进，保留换行、空行以及字符串和注释中的内容。C++ 支持常见模板、指针与引用、流输入输出及多行表达式。例如 cout<<i<<" "<<n<<endl; 会整理为 cout << i << " " << n << endl;。

“高亮排版”“生成代码块”“粘贴为代码”使用此设置；“仅改配色”“统一字色”和只更新边框不整理文字。取消“自动整理代码”后，关闭状态会保留。

常见 C/C++、Java、C#、JavaScript/TypeScript、Go、Python 和 JSON 使用基础规则；通过“自动整理代码”旁的“缩进”选择每级 1～8 个空格，默认 4 个，Python 保留已有缩进层级。不确定或未支持的语法可能保持原样。这是基础整理，不会补充括号、拆分语句或重排代码。

选择输出方式

类型适用场景
逐行表格每条代码占一行，使用 PowerPoint 表格工具编辑。带窗口底板时，需将表格与底板一并选中移动。
组合文本框每行都是可编辑文字，可与窗口底板组合，便于整体移动。

勾选“行号”并设置起始数字可显示行号。读取已有表格时，若首列数字属于代码或数据，请在“生成选项…”中选择“读取全部单元格”。

调整外观与边框

“外观”组提供背景与“模拟窗口”开关。“外观设置…”可调整背景色、主题字形、窗口底色、装饰按钮、阴影、内边距和圆角。开启模拟窗口后使用窗口底色，普通背景设置暂时停用。

设置窗口中的“保存”只保存偏好。普通背景与字形通过“高亮排版”应用；窗口外观通过“生成代码块”应用。

“输出 → 选项 → 表格边框”中的“行号分隔线”“行间横线”和“表格外框”可自由组合。点击“应用到选中表格”只更新边框，保留文字、颜色、字体、背景和位置。组合文本框不使用表格边框。

替换与合并

选中代码块并勾选“替换原对象”，再生成即可更新。表格带窗口底板时，请同时选中表格与底板。仅在新代码块生成成功后删除原对象；未勾选时保留原对象。

“粘贴为代码”也使用此开关：有选择时替换选中的文字对象，没有选择时直接插入。

“生成选项…”可将多个所选对象合并，按阅读顺序排列，中间保留一空行。

字号与放置

生成和粘贴使用选项卡设置的字号，从所选目标的左上角放置。合并多个对象时，使用阅读顺序中第一个目标的位置；表格与窗口底板一并选中时，使用底板的左上角。

粘贴时未选中目标，默认从幻灯片左上角向右、向下各 48 pt 处插入。生成后可继续移动对象；撤销操作可按 Ctrl+Z。

语言与主题

语言可从列表选择，也可输入 cpp、python、js、ts 等简称。Arduino 使用 C++ 语法。不使用背景时，请选择与幻灯片底色相配的主题。

“更多操作 → 导入主题…”支持 VS Code 的 JSON / JSONC 配色主题。导入后请保留主题文件及其引用文件。开启“使用主题字形”会应用主题指定的粗体、斜体和下划线。

帮助与问题排查

“帮助 → 运行状态”显示最近操作、引擎目录及语言和主题列表状态。“帮助 → 关于”显示版本与作者。

遇到问题时，可在“帮助 → 问题排查”中开启“记录诊断日志”，重现后打开日志。排查完成后关闭记录；已有日志可通过“清理日志…”删除，不影响课件。

代码在本机处理，不上传、不执行；日志不记录代码正文。语言与主题列表不完整或引擎无法启动时，可重新运行安装程序修复依赖。

安装与升级

保存课件并退出 PowerPoint，再运行安装包，完成后重新打开 PowerPoint。已有依赖可用时会复用；首次安装或修复依赖需要联网，无需手动安装 Node.js。
