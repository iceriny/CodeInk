# 基础代码整理规则

整理器先识别完整运算符，再区分流/移位运算、模板闭合、单目运算和类型声明，不依赖 `cout`、`cin` 等固定变量名。

## 调研结论与取舍

空格规则需要考虑符号所在的位置。clang-format 分别提供赋值符号、控制语句括号、模板角括号和指针/引用的设置，还允许声明模板名、类型名及空白敏感宏。这说明相同符号不能仅按字符替换。[clang-format 官方选项](https://clang.llvm.org/docs/ClangFormatStyleOptions.html)

Python 的规则也有例外：普通赋值、默认参数/关键字参数、带类型注解的默认参数和切片，空格约定不同。[PEP 8：表达式与语句中的空白](https://peps.python.org/pep-0008/#whitespace-in-expressions-and-statements)

本项目采用固定的基础规则，继续保留换行、空行和代码内容，不引入完整格式化引擎。对判断不清的位置保守保留；这不是 clang-format 或 PEP 8 的完整实现。

## 已适配的常见形式

| 类别 | 示例结果 | 处理方式 |
|---|---|---|
| 流输出、流输入 | `cout << x << endl; cin >> a >> b;` | 每个完整符号两侧一空格，字符串内部不动 |
| 移位 | `mask = 1 << n; x >>= 2;` | `<<`、`>>`、`>>>` 及对应复合赋值 |
| 算术 | `x = a * b + c / d - e % f;` | 区分二元算术与单目符号 |
| 比较、逻辑 | `a < b && b >= c` | 包括 `== != <= >= === !== <=> && ||` |
| 按位运算 | `x = (a & b) | (c ^ d);` | 保留类型后的指针/引用形式 |
| 复合赋值 | `x += y; x &= mask; x **= 2;` | 按完整符号处理，不拆成两个符号 |
| 空值运算 | `x = a ?? b; x ??= c;` | 不改成员访问 `obj?.value` |
| 三目表达式 | `ok ? std::max(a, b) : arr[i]` | 跟踪配对及括号层级，不把 `::` 当作分支冒号 |
| 控制语句 | `if (x) { f(); }`、`for (;;) { break; }` | 关键字与左括号之间一空格；不补换行或花括号 |
| 调用、下标 | `f(a[i], b)` | 去掉调用前和括号内边缘的多余空格 |
| 逗号、分号、冒号 | `f(a, b)`、`for (auto& x : xs)` | 根据参数、循环、数据字段等位置处理 |
| Python 参数 | `f(x=1)`、`def f(x: int = 1):` | 普通参数等号紧贴，带注解的默认值保留两侧空格 |
| Python 运算 | `a ** b`、`a // b` | 保留调用处 `*args`、`**kwargs` |
| 块与 JSON 缩进 | 每级 1～8 空格，默认 4 | JSON 数组参与层级；Python 保留原有缩进层级 |
| C++ 模板 | `vector<pair<int, int>>`、`array<int, (1 << 2)>` | 识别嵌套模板、默认类型参数和括号内表达式，保留闭合符号 |
| C++ 指针与引用 | `int (*fn)(int, int)`、`int (&items)[3]` | 区分类型声明、解引用和二元运算 |
| C++ 多行表达式 | 跨行调用、流操作和模板参数 | 在块缩进基础上增加一级续行缩进，闭合括号回到所在块层级 |

## 必须保留的内容

- 字符串中的空格、NBSP、Tab、转义和运算符是数据，保持原样。
- 科学计数法、十六进制浮点数和 C++ 数字分隔符按数字整体读取，例如 `1e-3`、`0x1.fp+2`、`1'000`。
- 简单模板/泛型参数中的 `>>` 保持闭合形式，例如 `vector<pair<int, int>>`；不当作右移添加空格。
- 单目符号、自增自减、成员访问、作用域和重载运算符名称保持完整，例如 `-n`、`*p`、`&x`、`i++`、`->`、`::`、`operator<<`。
- 注释和预处理指令不整理正文。C++ 大写宏调用及片段内 `#define` 声明的宏调用保留参数空白，因为字符串化可能使空白成为输出内容。
- C++ 中包含反斜杠续行时，整个片段保持原样，避免改变预处理指令或连续注释的范围。
- C++ 整理后再次比较预处理记号；若记号被合并或拆开，则回退到原文。这覆盖数字、字面量后缀、复合符号和双字符替代记号等边界。规则依据 [C++ 预处理记号](https://www.eel.is/c%2B%2Bdraft/lex.pptoken) 和 [翻译阶段](https://www.eel.is/c%2B%2Bdraft/lex.phases)。
- 复杂模板表达式、自定义小写类型名、外部小写宏和复杂插值仍有识别边界。JavaScript 正则/除法歧义处及复杂插值后可能保留部分后续代码。Shell、Markdown、YAML、HTML、JSX/TSX、Rust 等未覆盖语法保持原样。

## 生效与验证

默认开启，在“高亮排版”“生成代码块”“粘贴为代码”中生效。选项卡中的“缩进”设置每级空格数；“自动整理代码”可以直接关闭，关闭状态会保留。“仅改配色”“统一字色”和只应用边框不整理文字。

测试包含运算符/语言例外快照、重复整理结果一致性、3000 个不完整片段、原始与整理后 C++ 的编译及输出对比，以及表格/组合文本框生成和高亮的模拟测试。PowerPoint 实际视觉效果由安装包手动测试确认。
