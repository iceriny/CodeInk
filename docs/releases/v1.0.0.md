CodeInk 为 PowerPoint 提供本地代码高亮，生成可编辑的表格或组合文本框。

- 支持语言与主题选择、字体排版、行号、表格边框和模拟窗口。
- 基础代码整理默认开启，覆盖常见运算符、模板参数、指针声明和多行表达式。字符串、注释和识别出的宏参数保留原样；C++ 整理后会检查预处理词法单元，发现变化时保留原文。
- “高亮排版”“生成代码块”“粘贴为代码”直接可用，“自动整理代码”和“替换原对象”可在选项卡切换。
- 自动调整字号以适应页面空间，支持覆盖升级并保留用户设置。

下载 `CodeInk-Setup-1.0.0-online.exe`，保存课件并退出 PowerPoint 后安装。首次安装需要联网获取私有 Node.js 运行时和高亮依赖；日常使用在本机完成。

支持 Intel/AMD 64 位 Windows 上的 32/64 位桌面版 PowerPoint。安装包未数字签名。构建、引擎测试、原生模拟和 C++ 整理前后的编译运行对比由工作流执行；这些检查不等同于真实 PowerPoint 的视觉与操作验收。
