# CodeInk 1.0.0 · Windows / PowerPoint 人工回归清单

**尚未执行：以下不是通过记录。** 使用空白课件或课件副本，记录 Windows、Office 版本与位数、显示缩放、主题和字体。

## 升级与初始状态
1. 关闭所有 PowerPoint 窗口，从已有版本升级到 1.0.0；已有字体、语言、主题、行号、替换和窗口参数保留。
2. 全新安装时行号分隔线默认勾选，行间横线/表格外框不选；诊断日志未勾选。确认现有表格未因升级被自动改动。
3. 私有依赖匹配并完整时，断网升级应能复用；首装或修复需要在允许的网络下验证下载和实际 Shiki 自检。
4. x86、x64 Office 各测试一次；检查当前用户安装、加载、自检与卸载。不关闭组织安全策略。

## Ribbon 外观及状态
1. 顶部为代码、语言与主题、文字排版、外观、输出、CodeInk 六组；高亮排版、生成代码块、粘贴为代码为大按钮，所有组与按钮出现，无 XML 加载错误。
2. 在 100%、125%、150% 显示缩放和不同 PowerPoint 宽度下，检查标签、下拉宽度、菜单折叠。不得以宿主模拟测试替代此项。
3. “模拟窗口”切换时外观设置中的窗口参数正确启用/停用，重开后值保留。开启时普通背景参数变灰。
4. 直接切换“自动整理代码”和“替换原对象”；在“输出 → 选项 → 生成选项…”修改多选合并和自动字号上下限；关闭/重开 PowerPoint 后仍保留。
5. “帮助 → 运行状态”显示最近操作；“帮助 → 关于”可见作者 Iceriny、版本和插件位数，不混入安装步骤。“问题排查”中可打开和清理日志。

## 三类边框（核心）
1. 两列三行表格分别测试三开关的全部八种组合；核对四周、内部横线、行号分隔线，不出现对角线或相邻单元格边线不一致。
2. 只有竖边框时，代码块仅有行号与代码之间的一条分隔线。无行号单列表格此设置不产生左/右外边线。
3. 单行两列表格仅开横边框时没有内部横线；仅开外框时四边齐全。
4. 选已有表格任意单元格，在“输出 → 选项 → 表格边框”点击“应用到选中表格”。
5. 上一步前后比较代码、字色、字体、字号、行距、单元格填充、尺寸、位置和底板；这些均不改变。Ctrl+Z 撤销边框操作。
6. 多选两个原生表格批量设置边框；混入普通文本框时明确提示不支持，不能先悄悄修改一部分。
7. 仅改配色不改边框；高亮排版和生成代码块应用新边框。仅勾选复选框不会立即编辑旧表格。
8. 切到文本框输出时仍可修改选中的原生表格边框；新生成的组合文本框不受影响。

## 日志默认关闭
1. 在未创建新日志的安装目录测试启动插件、染色成功/失败、主题导入失败、查看关于及关闭 PowerPoint；不新增 CodeInk.log 或 engine/engine-error.txt。
2. 如果升级前已有日志，记录大小/修改时间，再执行上一步；关闭状态不应继续追加。
3. 开启诊断日志，复现一次操作，再取消勾选；启用期间有事件，关闭后停止追加。重启 Office 保留开关值。
4. “打开日志”在无文件时显示提示，不会自行开启日志；“清理日志…”需要确认，取消不能删除，确认后不修改开关或课件。
5. 检查引擎日志只含时间/类别/错误码，不含代码正文、堆栈、主题路径。
6. 默认关闭状态做联网依赖修复失败测试；仍有错误提示，未写 bootstrap-error.txt 或新增 npm debug/timing 日志。既有旧日志不应被当成新增日志。
7. 日志开关不应阻止依赖目录、自检标记、偏好、临时请求等正常功能文件的写入。

## 逐行与窗口旧功能回归
1. `a`、空行、`b`、尾换行生成四行表格；行号开启/关闭为两列/一列，98 开始显示 98/99/100/101，窄列不截断。
2. 12/18/28 pt、倍数/固定行距、中文/emoji、Tab、跨行注释和字符串分别检查。完整代码先解析，不能每行失去语法状态。
3. 原生表格+窗口仍是真表格，与底框仅同时选中；文本框+窗口为可编辑普通组合，整体移动正常。
4. 开/关按钮和阴影，修改圆角/底色/留白，替换重建；表格实际行高变化后底板覆盖完整，不遮挡末行。
5. 关闭窗口后重建可去掉底板；表格模式同时选择表格与底框再替换，单独表格不能删除周围对象。
6. 页面放满时生成和粘贴均直接插入；自动字号只在需要时按上下限调节，仍放不下也不弹出空间警告。勾选替换时测试有选择/无选择两种粘贴方式。
7. 批量分开/合并、取消、Ctrl+Z、保存重开/复制到其他页及卸载后的普通编辑回归。

## 基础代码整理
1. 输入连续流操作、嵌套模板、函数指针和多行调用，确认空格与缩进清晰，换行及空行保持。
2. 对含字符串、原始字符串、Tab、注释和宏的代码生成并读回，内容不被改写。关闭“自动整理代码”后空格和缩进保持原样。
3. “更多操作”中的仅改配色/统一字色不整理内容；高亮、生成与粘贴遵守自动整理开关。

发现问题时记录操作步骤、设置、报错码和截图。日志默认关闭，需要时主动开启复现；请勿提供无关课件内容。
