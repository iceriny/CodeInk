CodeInk 0.3.1 - Third-party components and notices

This small bootstrap EXE contains CodeInk's original native COM add-in,
JavaScript bridge, documentation and installer code. It does NOT contain the
Node.js runtime, Shiki package, or jsonc-parser package bodies. It retrieves
those from their official distribution channels with user consent at setup.
